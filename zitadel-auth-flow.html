Zitadel SSO — Authorization Flow

OIDC Authorization Code + PKCE — Monarc FrontOffice

🖥 User Browser
⚙️ Monarc PHP Server
🔐 Zitadel IdP
1
User clicks
"Login to Monarc with SSO"
GET /api/auth/zitadel/login
2
Generate PKCE
& CSRF state
loginAction() generates:
code_verifier → random 32-byte secret code_challenge = SHA256(verifier) state → CSRF token nonce → replay guard 🛡 PKCE 🛡 CSRF
Stored in HttpOnly cookies (5 min TTL)
3
Redirect browser
to Zitadel
302 → Zitadel /oauth/v2/authorize
client_id, redirect_uri response_type=code scope=openid profile email … state, nonce, code_challenge code_challenge_method=S256
4
User authenticates
on Zitadel UI
User enters credentials
Zitadel handles MFA & session
Issues one-time authorization code
5
Zitadel redirects
back with code
302 → /api/auth/zitadel/callback ?code=ABC&state=xyz
302 redirect with code + state
6
Validate CSRF
state
callbackAction() reads cookie:
storedState ← from HttpOnly cookie stateParam ← from ?state= query param hash_equals(storedState, stateParam)
Mismatch → 400 rejected 🛡 CSRF check
7
Exchange code
for tokens
(backchannel)
POST /oauth/v2/token grant_type=authorization_code code=ABC code_verifier ← from cookie Authorization: Basic clientId:secret 🛡 PKCE verify 🛡 Backchannel only
Returns: access_token id_token (JWT, RS256)
8
Validate
id_token JWT
GET /oauth/v2/keys → fetch JWKS
Verify RS256 signature
iss = our Zitadel domain aud = our client_id nonce = what we sent in step 3 exp checked by firebase/php-jwt 🛡 Signature verify 🛡 Replay guard
GET /oauth/v2/keys ← JWKS public keys
9
Fetch userinfo
& find/create
Monarc user
GET /oidc/v1/userinfo (Bearer token)
Verify sub matches id_token
Check email_verified
Lookup user by email in DB
Auto-create if not found 🗄 DB lookup/create
{ email, name, sub, … }
10
Issue Monarc
token & redirect
302 → http://localhost:5001/ #token=MON_TOKEN&uid=123 &language=1&idToken=JWT
Generate Monarc token
Save to user_tokens table
302 redirect to frontend 🗄 user_tokens saved
11
Frontend captures
token & logs in
layout.phtml <script> runs before Angular:
hash → sessionStorage → rewrite to #/ Angular boots → ClientLoginCtrl
sessionStorage → UserService.setToken() GET /api/users-roles (with Monarc token)
→ navigate to #/client/project
GET /api/users-roles ← { roles }
